# Data Structures and Algorithms in C++

This repository is a hands-on C++ practice workspace focused on:

- C++ basics and syntax
- Data structures and algorithms
- STL containers and iterators
- Sorting and utility algorithms
- Pattern printing exercises
- Array and problem-solving practice

## Repository Structure

- `1_Basics/` — beginner C++ programs covering variables, loops, functions, arrays, and references
- `2_STL/` — Standard Template Library examples including vectors, lists, stacks, queues, maps, sets, and algorithms
- `3_Pattern_printing/` — programs that print numeric and star patterns
- `array/` — array-focused exercises and practice files
- `DOCUMENTATION.md` — notes and quick references
- `input.txt` and `output.txt` — sample I/O files used with local execution workflows

## How to Compile and Run

From the repository root, compile a C++ file with:

```bash
g++ -std=c++17 path/to/file.cpp -o output.exe
```

Then run it:

```bash
./output.exe
```

On Windows with MinGW/MSYS, the pattern is usually:

```bash
g++ -std=c++17 file.cpp -o file.exe
file.exe
```

## Example

```bash
g++ -std=c++17 1_Basics/2_MyFirstProgram.cpp -o hello.exe
./hello.exe
```
